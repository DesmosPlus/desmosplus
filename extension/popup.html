Editable helpers

Add graph definitions for functions Desmos does not provide natively.

f_sinc(x) = 1 if x = 0; otherwise sin(pi*x)/(pi*x)
f_clamp(x,a,b) = min(max(x,a),b)
f_lerp(a,b,t) = a + (b-a)*t
f_frac(x) = x - floor(x)
f_hypot(x,y) = sqrt(x^2 + y^2)
f_logistic(x) = 1/(1 + e^(-x))
f_sign(x) = 1 if x > 0; -1 if x < 0; otherwise 0
f_roundto(x,n) = round(10^n*x)/10^n
f_versin(x) = 1 - cos(x)
f_haversin(x) = sin(x/2)^2
f_asinh(x) = ln(x + sqrt(x^2 + 1))
f_acosh(x) = ln(x + sqrt(x^2 - 1))
f_atanh(x) = ln((1+x)/(1-x))/2
f_wrap(x,a,b) = a + mod(x-a,b-a)
