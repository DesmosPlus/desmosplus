Desmos+ Extension Privacy Policy

Effective date: August 16, 2026
Last updated: August 16, 2026

This policy applies to the Desmos+ edition distributed through the Chrome Web Store. It explains how the extension handles information. Desmos+ is designed so its graph transfer, function library, starter ticker, autosave, dark mode, SVG and OBJ conversion, and audio conversion features run locally in the browser. The developer does not operate a server that receives those files or graph contents.

Information Handled

Graph and website content

When a user requests an import or export, Desmos+ reads or writes the active supported Desmos calculator state. That state can include expressions, folders, tables, notes, sliders, viewport settings, graph titles, and other user-generated graph content. The extension also reads the active tab URL to identify the calculator type, offer graph window options on unsupported pages, and include source information in an exported file.

Files selected by the user

Desmos+ processes graph files, SVG files, OBJ files, audio files, and DesAudify schema files that the user explicitly selects. Processing occurs locally in browser memory. Generated graph files and shard ZIPs are downloaded only when the user requests them.

Extension preferences

Desmos+ stores local on/off preferences for dark mode and autosave. These preferences are not sent to the developer and can be removed by turning the features off, clearing the extension's stored data, or uninstalling the extension.

How Information Is Used

  • To export and import Desmos graph state.
  • To convert selected SVG, OBJ, and audio files into editable Desmos content.
  • To add or remove a user-requested starter ticker in the active 3D graph.
  • To add or remove user-requested function definitions in the active graph.
  • To create user-requested downloads.
  • To apply the user's dark-mode preference on supported Desmos pages.
  • To request periodic saves on eligible official Desmos graphs when the user enables autosave.

Collection, Sharing, and Sale

Desmos+ does not send graph state, selected files, extension usage analytics, or personal information to the Desmos+ developer. The developer does not sell user information, use it for advertising, or share it with data brokers.

Opening external links or using the official Desmos website can cause the browser to communicate with those services under their own policies. Desmos+ does not send graph state or selected files to the Desmos+ developer or an independent DesmosPlus service. When autosave requests Desmos's native save action, the official Desmos website may store that graph in the signed-in Desmos account under Desmos's own privacy policy.

Storage and Deletion

Selected files and conversion data are normally retained only in browser memory for the active operation. User-requested downloads remain wherever the user saves them. The Chrome Web Store edition does not retain graph, SVG, OBJ, audio, or schema contents in extension storage. It retains only the dark-mode and autosave preferences described above.

Remote Code

Desmos+ does not download remote JavaScript into the extension or execute it with extension privileges. The OBJ importer, DesAudify, Canvas UI Flame Wrap, FFT, and the code used to add the in-page overlay are included in the extension package submitted for review. The optional graph window and overlay display the documented DesmosPlus calculator as a separate web page. That cross-origin page does not receive access to Chrome extension APIs or the surrounding website.

Chrome Web Store Limited Use

Desmos+ uses information received from Chrome APIs only to provide and improve the user-facing features described in this policy. It does not transfer that information except as necessary to provide a user-enabled feature, for security purposes, to comply with applicable law, or as part of a merger or acquisition. It does not use or transfer information for personalized advertising, creditworthiness, or lending purposes. Humans do not read user data unless the user gives specific consent for support, access is required for security or legal reasons, or the information has been aggregated and anonymized for internal operations.

Changes

This policy may be updated when extension behavior or legal requirements change. The effective date at the top of this page will be revised when that happens. Material changes to data handling will also be disclosed through the extension or its store listing when required.

Contact

Questions and privacy requests can be submitted through the Desmos+ support page.

Independent project: Desmos+ is not affiliated with, endorsed by, or maintained by Desmos Studio PBC. Desmos has a separate privacy policy that governs its own service.
