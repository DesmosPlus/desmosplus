Desmos+ Support

Use this page for extension setup, troubleshooting, bug reports, and privacy questions.

Supported Pages

  • Graph transfer: Desmos Graphing, 3D, Geometry, Notebook, Matrix, Four Function, and Scientific calculators.
  • SVG conversion: Desmos Graphing and Geometry.
  • DesAudify audio conversion: Desmos Graphing Calculator.

Quick Troubleshooting

Controls are disabled

Open a supported page on desmos.com, wait for the calculator to finish loading, and reopen the Desmos+ popup.

An update is not visible

Open chrome://extensions, find Desmos+, select Reload, and reopen the popup. Store-installed versions update through Chrome after the update is approved and published.

A graph imports but is not saved

Import changes the current calculator state. Use Desmos Save if the graph should remain in the user's Desmos account or graph library.

Audio conversion is slow or silent

Use Auto mode for a smaller graph, keep the Desmos tab active, and wait for processing to finish. Then unmute Desmos audio and click the generated title. High FPS, polyphony, long files, and MAX mode can use substantial CPU and memory.

Report a Problem

Open an issue in the DesmosPlus issue tracker. Include:

  • The Desmos+ version from chrome://extensions.
  • The browser name and version.
  • The calculator page being used.
  • Clear steps that reproduce the problem.
  • The exact error text and a screenshot when useful.

Do not attach private graph exports, audio files, HAR captures, account cookies, or other information that should not be public.

Privacy Requests

Privacy questions can be filed in the issue tracker without attaching private data. The extension's data handling is described in the Desmos+ Extension Privacy Policy.
