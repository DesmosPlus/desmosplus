Desmos+

Graph transfer, custom functions, autosave, dark mode, SVG and OBJ conversion, and audio creation tools for Desmos.

Desmos+ works with supported official Desmos calculators. It transfers complete graph state, adds reusable function definitions and a starter ticker, periodically saves eligible signed-in graphs when enabled, adds a persistent dark mode, converts static SVG artwork and OBJ geometry into editable equations, and creates playable Desmos audio graphs with DesAudify.

Features

  • Import and export portable .desmos graph files.
  • Open a separate graph window or a movable, resizable in-page calculator that minimizes into a floating DesmosPlus icon.
  • Preserve expressions, folders, tables, sliders, notes, and supported animation state.
  • Toggle a locally stored dark mode across supported Desmos pages.
  • Optionally request a save every 60 seconds on saved signed-in 2D graphs.
  • Convert static SVG paths and shapes into editable Desmos equations.
  • Import OBJ geometry into Desmos 3D with direct or optimized indexed equations.
  • Add a native starter ticker for elapsed-time animation without replacing an existing ticker.
  • Add and remove a folder of reusable functions that are defined as editable Desmos equations.
  • Create audio graphs with Auto, High quality, MAX, and Custom conversion modes.
  • Download large audio projects as individually pasteable graph shards.
  • Process selected graph, SVG, OBJ, and audio files locally in the browser.
